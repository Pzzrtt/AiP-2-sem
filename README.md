GUI+API

Принцип работы программы
Пользователь вводит логин GitHub в текстовое поле.
После нажатия кнопки «Найти» вызывается функция поиска.
Программа формирует URL-адрес для обращения к GitHub API.
С помощью библиотеки Requests отправляется HTTP GET-запрос.
GitHub возвращает информацию о пользователе в формате JSON.
Полученные данные преобразуются в объекты Python.
Информация выводится в графическом интерфейсе.
Дополнительно выполняется запрос для получения списка репозиториев пользователя.
Репозитории отображаются в отдельном списке приложения.

pip install -r requirements.txt
